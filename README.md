### LeetCode 题解
- `LeetCode.py` — LeetCode 题解合集：
  - 滑动窗口 / 哈希：无重复字符的最长子串、滑动窗口最大值（单调队列）
  - 链表：合并两个有序链表、反转链表（迭代 / 递归）、分隔链表、删除链表中的节点、随机链表的复制、链表的中间节点、相交链表、环形链表 II
  - 栈与队列：有效括号、最小栈、用栈实现队列、字符串解码（栈 / 递归）、验证栈序列
  - 双指针与哈希：两数之和 II（有序数组）、三数之和、数据流的中位数（双堆）、有效的字母异位词、第一个唯一字符、同构字符串、判断子序列
  - 字符串：反转字符串中的单词、字符串相加、旋转字符串、Z 字形变换、字符串转换整数
  - 矩阵：螺旋矩阵、螺旋矩阵 II、旋转图像（拷贝矩阵 / 原地修改）
  - 二分查找：二分查找、第一个错误的版本、寻找旋转排序数组中的最小值 II
  - 数组：寻找数组的中心下标（前缀和）、寻找重复数（原地交换 / 快慢指针）、数组中的第 K 个最大元素（排序 / 快速选择）
  - 二叉树：二叉树的层序遍历、锯齿形层序遍历（三种解法）、最近公共祖先、二叉搜索树中第 k 小的元素、二叉搜索树的最近公共祖先（通解 / BST 特性）、二叉树的最大深度（DFS / BFS）、路径总和 II、翻转二叉树（递归 / 迭代）、对称二叉树、平衡二叉树（自底向上 / 自顶向下）、从前序与中序遍历构造二叉树、二叉树的序列化与反序列化（BFS）
  - 图 / 拓扑排序：课程表（BFS + 入度表 / DFS 三色标记）
  - 回溯 / DFS：全排列、全排列 II（去重）、组合总和（可重复选取）、组合总和 II（去重 + 单次选取）、单词搜索（网格 DFS + 原地标记）
  - 数学 / 快速幂：Pow(x, n)（二进制快速幂）
  - 动态规划：斐波那契数列、爬楼梯、一维数组的动态和、买卖股票的最佳时机
