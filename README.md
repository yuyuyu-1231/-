# 算法练习记录（Python）

个人数据结构与算法练习仓库，用 Python 实现，记录学习过程与思考。

## 练习清单

### 查找
- `二分查找1.py` — 二分查找及变体（查找插入点、查找左边界）；哈希优化（两数之和）

### 排序
- `排序算法.py` — 基数排序

### 分治
- `分治算法.py` — 分治法实现二分查找
- `汉若塔问题.py` — 汉诺塔问题

### 回溯
- `回溯：全排列问题.py` — 全排列
- `回溯：n皇后问题.py` — N 皇后
- `回溯算法：子集合问题.py` — 子集和 II（含重复元素）
- `回溯问题.py` — 回溯算法通用框架（选择 / 撤销 / 剪枝）

### 动态规划
- `动态规划.py` — 爬楼梯（暴力 / 记忆化 / DP / 空间优化）、带约束爬楼梯、最小花费爬楼梯、最小路径和、0-1 背包、零钱兑换 I/II、编辑距离

### 贪心
- `贪心算法.py` — 最大切分乘积、硬币找零、分数背包、最大容量问题

### 树与二叉树
- `二叉搜素树.py` — 二叉搜索树实现
- `数据结构二叉树赋值.py` — 列表建二叉树与层序遍历
- `数据结构二叉树赋值数组.py` — 数组表示法实现二叉树
- `构建二叉树问题.py` — 由前序 + 中序遍历构建二叉树

### 堆
- `堆.py` — 大顶堆实现
- `建堆操作.py` — 建堆操作
- `基于堆查找数组中的最大值.py` — Top-K 问题（堆解法）

### 图
- `对于图的操作邻接矩阵.py` — 邻接矩阵表示
- `对于图的操作邻接表.py` — 邻接表表示
- `无向图的广度优先搜索.py` — 无向图 BFS 遍历

### LeetCode 题解
- `LeetCode.py` — 无重复字符的最长子串（滑动窗口 / 动态规划 + 哈希表）、合并两个有序链表、反转链表（迭代 / 递归）

### 其他
- `上课用.py` — 课堂练习（NumPy 成绩相似度矩阵）
